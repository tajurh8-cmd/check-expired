CREATE LABEL EXPIRED - INPUT + LIST DATA BARANG

Alur:
1. Ketik PLU/barcode lalu cari, ATAU pilih "Ambil dari List Data Barang".
2. Data list barang diambil dari edItems toko aktif (maks 300 item).
3. Produk, tanggal expired, dan RH terisi dari data yang dipilih.
4. Tentukan jumlah label.
5. Periode label AUTO berdasarkan jarak expired:
   <6 Bulan, 6-12 Bulan, 1-2 Tahun, >2 Tahun.
6. Tambah ke list label.
7. Preview lalu print A4 Landscape 4 kolom.

Catatan:
- Halaman ini tidak menambah data baru ke edItems; hanya menyiapkan label.
- Lookup manual memakai master datasumber dan aturan PLU/barcode yang sama dengan Input Expired.
- FCM, scanner, dan fitur lain tidak diubah.
