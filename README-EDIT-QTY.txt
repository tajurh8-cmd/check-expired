UPDATE DUPLIKASI & EDIT QTY

Aturan duplikasi edItems:
- storeid sama
- rak sama
- PLU sama
- BARCODE master/sourceBarcode sama
- tanggal expired sama

Jika sama, aplikasi tidak membuat data baru.
Muncul dialog: Item sudah ada - Edit QTY?
Jika dipilih Edit QTY, user memasukkan QTY baru dan data existing di-update.

Catatan: QTY baru menggantikan QTY lama, bukan ditambahkan.
