JADWAL RAK BULANAN PER USER

- Jadwal tidak lagi berdasarkan Senin-Minggu.
- Setiap tanggal dalam bulan dapat memilih rak berbeda.
- Jadwal disimpan per STORE + USER + BULAN di koleksi JadwalRakUser.
- Hari OFF cukup pilih "OFF / Tidak dijadwalkan".
- Saat halaman Input dibuka, sistem mengambil jadwal tanggal hari ini milik user yang sedang login.
- Rak hanya menjadi default; user tetap bebas mengganti rak.
- Halaman Jadwal dapat menambahkan rak baru. Rak baru masuk ke master Rak milik toko.
